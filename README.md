# AquaHero 💧🌍

AquaHero is a sustainability and smart waste management mobile application developed using React Native and Expo Go. The application spreads awareness about water conservation, waste segregation, recycling, and eco-friendly living through interactive learning modules, quizzes, rewards, and waste pickup features.

---

# 📱 Features

## 📚 Learning Modules

Users can learn about:

* Composting
* Rainwater Harvesting
* Zero Waste Lifestyle
* Plastic-Free Living
* Solar Energy
* Grey Water Reuse
* Waste Segregation
* Ocean Care
* Soil Health
* Eco Fashion

Each module contains educational information with images.

---

## 📝 Quiz System

* 100 environmental awareness questions
* Multiple choice answers
* Earn points for correct answers
* Improves sustainability knowledge

---

## 🚛 Waste Pickup Feature

Users can:

* Select Wet Waste or Dry Waste
* Capture waste images using camera
* Share GPS location automatically
* Schedule waste collection

---

## 🎁 Rewards System

Users earn eco-points by:

* Completing learning modules
* Attending quizzes
* Scheduling pickups

Points can be redeemed for:

* Eco Tote Bags
* Bamboo Toothbrushes
* Steel Bottles
* Saplings
* Recycled Products

# ⚙️ Installation Steps

## Step 1: Install Node.js

Download and install Node.js:
[https://nodejs.org/](https://nodejs.org/)

---

## Step 2: Install Expo CLI

Open terminal and run:

```bash
npm install -g expo-cli
```

---

## Step 3: Create Expo Project

```bash
npx create-expo-app AquaHero
```

---

## Step 4: Open Project Folder

```bash
cd AquaHero
```

---

## Step 5: Install Dependencies

```bash
npm install expo-image-picker expo-location
```

---

## Step 6: Replace App.js

Copy your AquaHero code and paste it into:

```bash
App.js
```

---

## Step 7: Add Assets Folder

Create an `assets` folder and add all images used in the project.

Example:

* composting.png
* rainwater.jpg
* Eco Tote Bag.jpg
* stay hydrated.jpg

---

## Step 8: Run the Project

```bash
npx expo start
```

---

## Step 9: Open in Mobile

1. Install **Expo Go** from Play Store
2. Scan the QR Code shown in terminal/browser
3. App will open on your mobile device
